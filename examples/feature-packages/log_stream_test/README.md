# 实时日志稳定性测试

这个功能包只用于验证平台运行闭环，不访问网络，也不读取数据源。

## 行为

- 默认输出 100 条结构化日志；
- 每条日志间隔固定为 0.3 秒，默认运行约 30 秒；
- `log_count` 可以在客户功能配置中调整为 1～1000；
- 每一轮都会调用 `ctx.raise_if_cancelled()`，可以验证主动停止；
- 正常完成时输出“实时日志稳定性测试完成”，随后由 Runner 写入平台终态事件。

## 验收

1. 上传并等待状态变为“可运行”；
2. 保持默认 100 条并运行，确认日志持续出现且结束后页面仍可操作；
3. 再运行一次，在日志输出过程中点击“停止任务”；
4. 确认任务进入“已停止”，页面仍可返回记录、下载日志并切换菜单。
