# 第三方软件与许可证

## 1. 平台组件

主要第三方组件及锁定版本以以下文件为准：

- 后端：`backend/pyproject.toml`；
- 前端：`frontend/package-lock.json`；
- 容器基础镜像和构建工具：`Dockerfile`；
- 功能包依赖：各包的 `requirements.txt`。

依赖清单是审计基线，不代表所有上游组件由本项目团队提供商业支持。上线前应由甲方按其开源软件管理制度完成许可证和漏洞审查。

平台从 1.1.0 起使用 `openpyxl 3.1.5` 生成最终报表 XLSX。它是平台运行依赖，与功能包是否自行使用 openpyxl 无关；精确版本由后端项目清单和更新包 wheelhouse 同时锁定。

## 2. 7-Zip

容器为 RAR 功能包读取内置 7-Zip 命令行程序。许可证原文随源码位于：

```text
docs/third-party/7zip-license.txt
```

Docker 构建通过固定版本下载地址和 SHA-256 校验取得对应架构二进制。

## 4. OZON 功能包依赖

OZON 适配包声明：

- pandas 3.0.5；
- openpyxl 3.1.5；
- requests 2.34.2；
- 上述包解析出的间接依赖。

带 wheel 的离线包仅用于清单声明的 Linux/Python/CPU 组合。wheel 内自带的 `*.dist-info/licenses` 或上游元数据应随发布审查保留。
