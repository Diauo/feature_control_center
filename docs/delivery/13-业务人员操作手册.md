# 业务人员操作手册

> 本手册面向**日常使用平台的业务人员**（运营、客服、仓储对接等）。
> 服务器的安装、升级、账号与权限配置由系统管理员负责，遇到本手册未涵盖的问题请联系管理员。

---

## 1. 登录平台

1. 打开浏览器访问平台地址（由管理员提供，例如 `http://192.168.3.211:49088`）；
2. 输入管理员为你分配的**账号**和**密码**登录；
3. 首次登录或密码到期后，系统会要求修改密码；
4. 忘记密码请联系管理员重置（为安全起见，平台不通过聊天工具发送密码）。

> 请勿多人共用同一个账号——所有操作都有审计记录，需要能对应到真实操作人。

## 2. 界面速览

- **左上角「客户」选择框**：你只能看到自己被授权的客户。做任何操作前，先确认当前选中的客户是你要操作的客户；
- **左侧菜单**：你能看到哪些菜单，取决于管理员给你的授权。业务人员常用的是：
  - **工作台** —— 执行功能、替换数据源；
  - **运行记录** —— 查看任务结果、业务报表、导出 Excel；
  - **定时任务** —— 查看与管理周期性自动执行（如被授权）。

## 3. 日常工作一：运行功能（工作台）

1. 左上角选择正确的**客户**；
2. 在工作台列表中找到要执行的功能（如「OZON库存同步」）；
3. 确认卡片上的状态是 **「可运行」**，点击 **「运行」** 按钮；
4. 页面提示"任务已提交"即成功排队（若你有「运行记录」菜单权限会自动跳转到本次运行详情）；
5. 运行期间可以停留在详情页看**实时日志**；也可以关闭页面——**关闭网页不影响任务执行**，稍后回运行记录查看即可。

**关于运行时长**：库存同步等功能的单次运行可能持续几十分钟到数小时（取决于商品数量与接口速度），属正常现象，无需一直守着。

**需要提前停止**：在运行详情页点击「停止」，平台会先请求脚本收尾（已处理的数据会正常落盘），请等待状态变为「已停止」再离开。

**紧急停止（急停）**：如果在前台发现了数据异常、需要立刻停止相关任务：

1. 在工作台找到对应功能的卡片（先确认左上角选择的客户正确）；
2. 点击卡片上的 **「急停」** 按钮——只要有运行中或排队中的任务，按钮就是红色可点击状态（没有任务时为灰色不可点）；
3. 在弹窗中确认，系统会立即请求停止**该功能当前所有运行中的任务实例**（排队中、启动中、运行中的都会被终止）；
4. 已处理的数据会正常落盘；未完成的部分可以稍后重新运行。

> 急停只用于止损，不会删除任何数据。任务停止后建议先核对现场情况再决定是否重新运行；情况不明时请联系管理员排查。

## 4. 日常工作二：替换数据源（工作台）

**什么是数据源**：某些功能需要你提供一份输入文件（例如库存同步的"控制表"）。每个客户、每个功能各有一份**当前生效**的数据源文件。

- **下载数据源**：点「下载数据源」可取得当前正在使用的文件，用于核对；
- **替换数据源**：点「替换数据源」上传新文件 → 系统会形成一份新修订（旧文件仍保留可追溯）；
- **生效时间**：新文件从**下一次运行**开始使用；正在执行中的任务不受影响；
- **格式要求**：文件格式（表头、列名、扩展名）必须符合该功能的要求，不要改动表头。例如库存同步控制表需要包含 `sku`、`store_code` 两列。

> 温馨提示：替换前建议先核对一次「下载」的旧文件作为对照，避免传错客户。

## 5. 日常工作三：查看结果与导出（运行记录）

### 5.1 运行列表

「运行记录」页展示任务的状态、业务结果汇总和完成时间。可按请求 ID、时间等条件筛选；页面支持刷新。

**执行状态含义**：

| 状态 | 含义 |
| --- | --- |
| 执行中 | 任务正在运行 |
| 成功 | 任务正常跑完 |
| 部分成功 | 跑完了，但有失败项（明细里能看到具体原因） |
| 失败 | 任务未能正常完成 |
| 已停止 | 被人工停止 |

### 5.2 运行详情：两个页签

- **实时日志**：脚本执行过程的详细记录（排查问题时使用）；
- **最终报表**：业务结果清单——**日常核对以这个为准**。

### 5.3 最终报表

- 顶部是**汇总数字**：总量、成功、失败、无数据、已跳过、未完成；
- 下面是**逐条明细**，每条包含商品/订单编号、状态和原因；
- 点击 **「导出 XLSX」** 下载完整报表（包含"执行汇总"和"结果明细"两个工作表，不受页面筛选影响）；
- 若显示 **"报表未完整"**：说明任务被停止/中断，**已处理的明细仍然保留**；建议结合失败项再跑一次。

**明细中的最终状态（finalStatus）常见含义**：

| 状态 | 含义 |
| --- | --- |
| `UPDATED` / `PUSHED` / `WROTE_BACK` | 处理成功（库存已更新 / 订单已推送 / 单号已回写） |
| `NO_CHANGE` | 与平台数值一致，无需更新 |
| `SKIPPED_ALREADY_EXISTS` | 已存在（重复数据），正常跳过 |
| `SKIPPED_NOT_IN_ME3` | ME3 中没有该商品数据，跳过（不算失败） |
| `NO_MATCH` | 未找到对应商品（请核对商品/条码） |
| `FAILED_ME3_QUERY` / `FAILED_REQUEST` | 接口查询失败，建议稍后重跑；持续失败联系管理员 |
| `FAILED_UPDATE` / `FAILED_PUSH` / `FAILED_WRITE` | 平台拒绝了本次操作，看明细里的原因 |
| `FAILED_INTERRUPTED` | 任务被中断，该项未完成判定 |

> 想快速定位某个商品/订单：导出 Excel 后按编号列筛选，比翻页面快。

## 6. 定时任务（如被授权）

- 「定时任务」页可查看该客户各功能的自动执行计划（每天 / 每周 / 每月 / 自定义 Cron）；
- 可新建、编辑、启用/停用（需先选择具体客户，"全部客户"视图下不能操作）；
- **注意**：系统离线期间的执行时点**不会补跑**，服务恢复后按下一次的排期执行；
- 排期使用系统统一时区（由管理员设置）；
- 建议：**先手工运行成功一次，再启用定时任务**。

## 7. 常见问题（FAQ）

**Q1：为什么「运行」按钮点不了？**
通常是该功能当前状态不是「可运行」：可能是"等待数据源"（需要先替换数据源）、"准备依赖中"（稍等或找管理员）、或功能被停用。把状态文字报给管理员即可快速定位。

**Q2：任务跑了很久，是不是卡住了？**
不一定。库存同步类功能本身耗时较长。可以先看实时日志是否有新记录；也可以用「停止」按钮安全停止后重试。

**Q3：报表里显示"这个功能没有提交结构化报表"？**
该功能包版本较旧、未适配报表。改用「实时日志」查看执行过程，或请管理员升级功能包版本。

**Q4：数据源传错了怎么办？**
重新点「替换数据源」上传正确文件即可，从下一次运行生效；错误内容不会影响正在运行的任务。

**Q5：历史记录能保存多久？**
默认 180 天（管理员可在系统设置中调整）。需要长期留存请及时导出 Excel。

**Q6：提示要输入密码？**
删除功能等敏感操作需要输入**你本人的登录密码**确认，属正常安全设计（不会要求管理员密码）。

**Q7：换了电脑/浏览器，任务会断吗？**
不会。任务在服务器上执行，与浏览器无关；登录任意电脑都能看到相同的运行记录。

## 8. 安全提醒

- 不共用账号、不把密码告诉他人；
- 不通过聊天工具发送平台密码或客户密钥；
- 敏感操作（删除等）平台会要求重新验证你的密码；
- 发现异常操作记录，第一时间联系管理员。

## 9. 名词速查

| 名词 | 说明 |
| --- | --- |
| 客户 | 平台管理的业务对象（店铺/公司维度），所有数据按客户隔离 |
| 功能 | 一个可执行脚本（如"OZON库存同步"），可手工或定时运行 |
| 版本 | 功能的代码版本；新版本上传后需要切换（由管理员操作） |
| 数据源 | 功能依赖的输入文件，按客户独立保存、可替换 |
| 任务 / 请求 ID | 每次运行为一条任务，有唯一请求 ID 用于追溯 |
| 最终报表 | 每次运行的业务结果清单，可导出 Excel |
| 定时任务 | 让功能按排期自动运行的计划 |
