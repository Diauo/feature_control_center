## 3. 构建环境限制

本次工作站未安装 Linux Docker Engine，不能在本机真实构建或启动 Linux OCI 镜像。交付生成器因此会把清单标记为 `source-build`，目标服务器首次安装时从源码构建。完全离线镜像必须在 Linux Docker 构建机执行 `deployment/build-offline-bundle.sh`，并在目标同架构服务器完成容器验收。

这一限制不影响源代码、功能包和文档的校验，但它是正式上线前必须关闭的发布门，不能用空文件或改名压缩包冒充 Docker 镜像。

## 4. 业务验证边界

OZON 包基于真实项目适配，但未使用生产凭据发起库存请求。原业务代码的 TLS、超时、重试和库存计算风险记录在 `04-Ozon适配与上线前检查.md`，由业务开发修复并通过测试店铺验收后才能启用。
