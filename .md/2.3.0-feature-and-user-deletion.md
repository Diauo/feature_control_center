# 2.3.0 功能与用户删除（保留审计与历史）

- 功能删除采用「软删除登记」：`customer_feature` 增加 `is_deleted/deleted_at/deleted_by`（迁移 0012）；删除后从工作台与列表移除，运行创建、配置、数据源、定时任务等入口全部关闭；
- 删除动作清除该客户的配置值（含密钥）、数据源修订（被运行引用的清空内容、未引用的整行移除）与定时任务；保留登记行、版本记录与全部历史运行（含日志与报表）；
- 重新上传同一功能包即恢复原登记：字节级相同复用既有版本，新版本则绑定新版本；从其他客户复制同样触发恢复；历史运行记录自然延续；
- 保护规则：有排队/运行中任务时拒绝删除；重复删除返回「已删除」；越权（无功能管理菜单/无客户范围）被拒；删除需重新验证密码；删除与恢复均有审计记录；
- 用户删除：可删除业务员账号（管理员与当前账号不可删）；会话、客户关联与菜单授权一并清理，历史审计保留账号快照；需重新验证密码；
- 测试：新增 6 个用例（软删保留历史与恢复、运行中保护、越权拒绝、用户删除与审计快照、管理员保护、最近认证），后端全量通过。
