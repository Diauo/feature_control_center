# 0.0.11 侧边栏文字导航改动记录

日期：`2026-09-09`  
版本：`0.0.11`

## 改动目标

去除左侧主导航中每个菜单项前的字符图标，降低界面噪声和不一致的装饰感，改为更克制的纯文字导航。

## 具体改动

- 删除导航数据中的 `symbol` 字段和导航按钮中的图标节点；
- 删除仅为导航图标服务的 `.nav-symbol` 样式，避免死代码；
- 在不改变侧边栏宽度、路由、权限可见性和移动端交互的前提下，微调文字导航的内边距；
- 保留顶部 `F` 品牌标识和底部服务状态点，它们分别承担产品识别和运行状态语义，不属于菜单装饰图标。

## 决策理由

原导航使用 Unicode 字符模拟图标，不同操作系统和字体的绘制差异较大，视觉重量也不一致。在不引入新图标库和额外依赖的前提下，纯文字导航更符合当前简洁、易部署的产品方向。

## 未改变的边界

- 不改动整体页面布局和侧边栏结构；
- 不改动后端接口、路由和权限判断；
- 不修改原 `features/` 目录；
- 不增加第三方 UI 依赖。

## 验证

- 前端 Vitest：2 个测试文件、5 项测试全部通过；
- `vue-tsc` 与 Node 配置 TypeScript 检查通过；
- Vite 生产构建通过；
- 新生产产物已同步至 Flask 静态目录；
- 本地界面重载后，辅助功能树中的 8 个主导航按钮均只包含文字标签，无图标节点。
