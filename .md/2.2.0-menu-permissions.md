# 2.2.0 业务员菜单权限与工作台权责整理

- 业务员账号改为**按菜单授权**：管理员在用户管理中逐账户勾选「工作台、运行记录、定时任务、功能管理、用户管理、客户管理、安全审计」；「系统设置」保持管理员专属；
- 后端对每个菜单对应的接口强制校验（403 `MENU_PERMISSION_REQUIRED`），前端导航与路由同步按授权显示；调整授权**即时生效**，无需重新登录；
- 新建业务员默认授权「工作台 + 运行记录」；存量业务员升级时回填「工作台、运行记录、定时任务」，升级前后能力一致（迁移 0011 新增 `user_menu_grant` 表）；
- 工作台职责收敛为「执行功能 + 替换数据源」：「上传功能包」入口移除（功能管理保留完整能力），「配置管理」移入功能管理页的功能卡片；
- 工作台点「运行」的跳转逻辑按权限区分：有「运行记录」权限跳转实时日志，没有则仅提示「任务已提交」；
- 后端测试新增菜单权限矩阵用例（默认授权、逐菜单 200/403、非法授权校验、授权即时生效、系统设置管理员专属），同步调整存量用例；前端测试覆盖工作台职责边界与运行跳转分支。
