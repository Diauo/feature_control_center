# 1.1.1 运行汇总与报表交付

日期：2026-09-11

## 变更原因

1.1.0 已经建立结构化报表、中文明细和 XLSX 生成能力。本次交付前复核发现，运行记录主表在任务尚未结束时仍使用“总数”措辞，并把预计但尚未处理的差额计入“未完成”。这会让业务人员把执行中进度误认为最终结果。

## 本次调整

- 运行中的主表改为“已处理 / 预计”，同时显示当前成功数和失败数；
- 运行中的预计差额不显示为“未完成”，只有终态才展示最终未完成数量；
- 终态主表继续显示总数、成功数和失败数，第二行显示无数据、跳过、未完成和报表完整性；
- 运行记录页面说明补充“业务结果”；
- 报表按钮改为更明确的“导出 XLSX”；
- XLSX 仍导出本次运行的全部明细，不受页面状态筛选和分页影响；
- 后端验证补充下载审计断言；
- 前端增加运行中进度与终态汇总的页面测试。

## 保持不变的边界

- 平台不解析任意日志 JSON，不识别 OZON 专用 `finalStatus`；
- 每条业务结果由功能脚本通过 `ctx.report` 提交；
- 平台不增加失败项重跑、商品查询或业务网络重试；
- 旧功能包继续运行，没有报表时明确显示“未提交报表”；
- 数据库迁移版本仍为 `0009_run_reports`，本次不新增数据表；
- 报表明细继续使用任务日志保留期限，汇总数字继续保留。

## 版本与交付

- 系统版本升级为 `1.1.1`；
- 完整测试、前端生产构建、交付包生成与校验统一由发布检查入口执行；
- 新交付包输出到桌面，不包含本地数据库、账号、密钥、客户数据源或运行日志；
- 交付完成后使用当前工作目录的数据启动本地 Web、Runner 和 Scheduler 供界面验收。
